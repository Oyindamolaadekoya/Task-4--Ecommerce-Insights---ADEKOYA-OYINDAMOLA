# Project 4: Data Visualization

**DecodeLabs Data Analytics Internship | Batch 2026**

## Overview
This project involved creating visual representations of data from a 1,200-row e-commerce customer orders dataset to communicate business insights clearly through charts and graphs using Microsoft Excel.

## Dataset
- **File:** Dataset_for_Data_Analytics.xlsx
- **Records:** 1,200 orders
- **Columns:** 14
- **Date Range:** January 2023 – June 2025

## What Was Done
- Created 5 charts to visualise key findings from the dataset
- Selected the most appropriate chart type for each data category
- Added data labels and insight captions to each chart
- Organised all charts into a structured multi-sheet Excel workbook

## Charts Created

| Chart | Type | What It Shows |
|---|---|---|
| Chart 1 | Bar Chart | Total Revenue by Product |
| Chart 2 | Pie Chart | Order Status Distribution |
| Chart 3 | Line Chart | Monthly Revenue Trend 2023–2025 |
| Chart 4 | Bar Chart | Revenue by Referral Source |
| Chart 5 | Grouped Bar Chart | Payment Method: Orders vs Avg Spend |

## Key Visual Insights
- **Chair** and **Printer** generate the highest revenue at ~$195K each
- **41.4%** of orders are Cancelled or Returned — visible in the pie chart
- **June 2024** was the peak revenue month at $68,068
- **Instagram** is the top acquisition channel at $275K revenue
- **FREESHIP** coupon drives the most revenue at $335K
- **Credit Card** users spend the most per order at $1,127
